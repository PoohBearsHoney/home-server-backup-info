Home Server Backup

A personal backup tool for the project owner's home server. It is intended to create encrypted recovery copies of selected application settings, databases, scripts, and game saves in the owner's Google Drive.

The backup setup is currently being configured. This website provides information about the tool; it does not provide a login, accept files, or give access to the server or its backups.

Why Google Drive access is requested

Once enabled, rclone will connect the backup tool to the owner's Google account. Restic will encrypt backup data before upload. Drive access is used to create, read, verify, restore, and maintain the tool's backup files, including removing old backup data under the owner's retention settings.

The tool is for its owner's use only and is not offered as a service to other users. It is not intended to read unrelated Google Drive documents.

Data and privacy

See the privacy policy for how authorization and backup data are handled, and the terms of use for the tool's limits.

Project contact

Contact the project owner through the project's GitHub repository. Do not post credentials, private server information, or backup data in public issues.
