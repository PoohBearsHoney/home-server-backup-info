Privacy policy

Effective November 13, 2026.

Home Server Backup is a personal-use tool operated by its project owner. This policy describes the intended Google Drive backup workflow as it is configured and enabled.

Data used and purpose

The tool uses Google authorization credentials to connect to the owner's Drive and manage its backup repository. Selected server files may include application configuration, databases, automation scripts, and game saves. Recovery configuration can contain sensitive information, so backup contents are encrypted with Restic before being sent to Drive.

Google Drive data accessed by the tool is used only to operate and verify backups, restore data at the owner's request, and maintain backup history. It is not used for advertising, sale, profiling, or training artificial intelligence models.

Storage and access

Authorization credentials are stored on the owner's computer or server with restricted access. Encrypted backup data is stored in the owner's Google Drive. The owner controls the recovery password and is responsible for keeping an independent recovery copy of it.

This public website and its repository must not contain backup contents, authorization tokens, encryption passwords, or private server configuration. The tool does not make the backup repository public.

Sharing and service providers

The tool does not intentionally share Google user data with other people. Google processes authorization and stores uploaded encrypted files as the chosen service provider. GitHub hosts this information website; its hosting privacy practices apply to visits. This site itself has no analytics scripts, forms, or advertising.

Retention and deletion

Backup history is kept according to the owner's configured retention and storage limits. Removing a backup snapshot may not immediately remove all underlying data because backup versions can share encrypted data. Repository maintenance is needed to reclaim eligible storage.

The owner can revoke the tool's Google access in Google Account settings. Revoking access stops future authorized access but does not automatically delete backups already stored in Drive. The owner can separately remove those files and any remaining local copies.

Contact and changes

Questions or policy updates can be raised through the project repository. Public issues must not include credentials or backup data. Changes to this policy will be published here with an updated date.
